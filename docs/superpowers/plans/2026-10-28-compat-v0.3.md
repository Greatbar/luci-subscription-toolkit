## Review focus

- Fetch works even when native generator/Selector is unavailable; never masks a state conflict.

- Unknown source layouts fail only native generation; never execute Podkop CLI during preflight.
- Rollback validates the staged old configuration before touching live UCI.
- LuCI never treats an unknown version as a global disabled state.
